# 🎤 Speaker knowledge base

The vault root is your whole speaker folder. Your original PPTX, PDF, video and photo files stay where they are. Notes in `_Base/` link to them.

## Navigate
| Section | What's inside |
|---|---|
| [[Speaker profile]] | Bio, numbers, credentials, videos, press. Single source of truth for media kits |
| [[How to use this vault]] | The workflow from request to debrief |
| [[Proofs]] | Thank-you letters, certificates, paid-talk contracts. Links only |
| `Topics/` | Your signature talks |
| `Events/` | One note per event or series |
| `Decks/` | One note per deck with full slide text. Search with Ctrl/Cmd+Shift+F |
| `Story bank/` | Reusable stories, cases, numbers, jokes, demos |
| `Inbox/`, `Ideas/` | Raw input |
| `Templates/` | Insert with Ctrl/Cmd+P → "Templates: Insert template" |
